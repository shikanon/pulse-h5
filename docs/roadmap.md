# 实施路线与验收

当前仅完成 M0。以下里程碑是完整 H5 的开发顺序，不是把 Web Player 当作最终产品。

| 阶段 | 交付范围 | 完成标准 | 状态 |
| --- | --- | --- | --- |
| M0 项目初始化 | 公开仓库、完整产品定义、架构与路线 | 定位覆盖完整客户端，明确依赖与未实现项 | 已完成 |
| M1 应用基础 | React/TS/Vite、三入口路由、启动配置、消费者 Web 会话 | 可运行，真实登录与退出、深链恢复、错误与维护状态可验收 | 待实现 |
| M2 发现与互动 | Feed、Player、点赞评论收藏、分享举报 | 浏览并游玩他人作品，退出恢复 Feed，互动状态持久化 | 待实现 |
| M3 创作闭环 | 原创、Remix、素材、生成、私有预览与发布 | H5 内独立完成生成发布，不依赖打开 iOS | 待实现 |
| M4 个人与传播 | 作品/草稿/版本、收藏最近、账号治理、公开分享与挑战 | 版本更新与撤销正确，个人状态一致，公开链接可传播 | 待实现 |
| M5 上线验收 | 移动适配、浏览器兼容、性能、恢复、正式部署 | 真机和线上核心链路通过，记录证据与限制 | 待实现 |

## M1 前置工作

- 明确并实现消费者 Web 登录，不能借用管理员登录。
- 核对 API 契约与 CORS，验证私有 Artifact 在浏览器的授权方式。
- 建立锁定依赖、类型检查、构建、业务测试与浏览器 E2E 门禁。
- 核对启动配置中的 iOS 专属字段，定义 H5 的维护和兼容策略。

## 核心用户链路

1. 游客打开 Home，浏览分页，进入他人公开作品并真实操作，退出回到原位置。
2. 点赞或评论触发登录，登录成功恢复意图；刷新后状态一致。
3. 从 Create 输入一句话，添加素材，生成，私有预览中真实交互，发布，再从 Feed 游玩。
4. 从原作发起 Remix，检查来源、继承与权限，生成并发布后仍有正确归因。
5. 作者修改已发布作品，私有候选不影响旧公开版本；选择候选发布后才切换。
6. 生成过程中刷新、后台切换、网络中断，再打开可恢复；取消或重试不产生重复任务。
7. 打开公开链接与挑战链接；撤销、下架、失效和版本不匹配各自正确处理。
8. Profile 查作品、草稿、版本、收藏与最近游玩，退出后私有状态不留给下个用户。

## 证据要求

每条链路记录环境、API/前端版本、浏览器与视口、真实操作、页面状态、目标结果、失败原因和限制。桌面模拟视口不能替代 iOS Safari、Android Chrome 和微信内置浏览器真机验收。

确定性本地 API 可验证状态机与页面流；真实模型生成、素材绑定和最终玩法需要单独执行 live 验收。构建成功、静态截图和 mocked API 测试都不能证明生产闭环完成。

至少检查 360、390、430px 视口与桌面布局，覆盖键盘弹出、底部安全区、游戏触控、返回导航、弹层焦点、弱网与后台恢复。所有可见主要按钮都需可用，不展示假的生成进度或不可执行的入口。

## 后续增强

PWA 安装、增强离线体验、搜索推荐、Inbox 等可在完整核心链路稳定后规划。公开内容权限与撤销优先于离线便利性。
