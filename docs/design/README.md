# 页面实现参照

当前实现以 `pulse-ios` 的 SwiftUI 页面和交互为准（本次核对提交 `8995d3900677ab21eebbce788754b3f2875e98f2`）。早期的 `pulse-h5-concept.png` 仅保留为历史概念图，不再作为布局验收基准；生成艺术封面不再作为作品缺省预览。

## 已对齐的页面与行为

- Home：精选/最新切换、直接运行当前作品、作者和单行主题摘要、点赞/评论/Remix/收藏/分享与安全选项。首次交互进入沉浸模式，只保留退出和浮动胶囊导航；退出不重建播放器。
- 导航：黑色背景、酸橙 `#b3ff14`、紫色 `#9452ff`、珊瑚色 `#ff5975`。Create 返回当前创作流程，重新点击 Home 回到首个作品。
- Create：原创/Remix/修改的上下文标题、保留要求、素材用途和出现位置、素材库/媒体/背景音乐入口、对话记录和返回预览。使用与 iOS 相同的私有 creation-context 序列化格式；草稿刷新后恢复。
- 生成与发布：成功生成自动打开私有预览；只有通过验收的候选版本提供发布入口。发布后回到最新 Feed 并定位作品。
- Profile：身份与三项指标、七种作品状态筛选、列表作品行、独立收藏/最近页面、版本历史和管理入口。
- 评论：1–5 星评分、登录前保留评论草稿、删除前二次确认。登录后恢复点赞/收藏意图。
- Sheet：浏览器返回优先关闭弹层，原生 dialog 管理焦点，嵌套弹层保持滚动锁定。

## 浏览器适配边界

H5 使用浏览器沙箱、Web 分享/剪贴板与文件选择器，不复制原生系统控件。桌面保持移动端内容宽度。无真实封面的作品显示中性占位，避免把概念图误当作作品结果。

源代码行为对照与桌面浏览器移动视口测试不能证明像素级一致；iPhone Safari/微信、软键盘、安全区和 Apple Web 登录仍需真机验收。确定性本地生成验证流程与协议，不证明真实模型的创作效果。
