# Pulse H5 产品定义

## 定位

Pulse H5 是 Pulse 面向消费者和创作者的完整 Web 客户端。用户不安装 iOS App，也应能完成“发现 → 游玩 → 原创或 Remix → 生成 → 预览 → 发布 → 分享 → 再次游玩”的完整闭环。

移动浏览器为主要使用场景，同时适配桌面浏览器。微信内置浏览器的登录、分享、音频和下载能力需专项验证，不以普通 Chrome 通过代替。

## 产品参照

初始化时参考 `pulse-ios` 的 `Pulse/App/PulseApp.swift`、`Pulse/Domain/PulseAPIClient.swift`、各 `Features` 模块及客户端页面设计 PRD。代码参照版本：`8995d3900677ab21eebbce788754b3f2875e98f2`。

以下内容是 H5 目标定义。iOS 或旧 Web Player 的已有实现不自动算作 H5 已实现。

## 信息架构

Home / Create / Profile 是三个常驻业务入口。Create 始终发起独立原创；Remix 只从明确的现有作品入口发起。未实现的 Inbox、私信和多人协作不展示占位入口。

以下路由已实现；能力验收状态见 `acceptance.md`：

| 页面 | 路由规划 | 核心行为 |
| --- | --- | --- |
| 首页 | `/` | Featured / Latest、分页、游玩、互动 |
| 原创 | `/create` | 新原创或恢复原创草稿，无父作品 |
| Remix | `/remix/:workId` | 验证原作权限，展示来源与继承范围 |
| 作品 | `/works/:workId` | 作品详情、互动、来源及作者操作 |
| 持续创作 | `/works/:workId/edit` | 修改作者当前私有候选版本 |
| 生成任务 | `/generations/:generationId` | 进度、Plan、失败恢复与跳转预览 |
| 私有预览 | `/works/:workId/preview` | 校验作者身份，试玩指定候选 Artifact |
| 公开分享 | `/a/:slug` | 无需安装 App 即可游玩；可继续进入 H5 Remix |
| 个人中心 | `/me` | 作品、草稿、收藏、最近游玩 |
| 版本历史 | 作品页内面板 | 面向作者的结果与版本关系 |
| 设置 | `/settings` | 账号、隐私、语言、诊断及使用统计选择 |
| 登录 | `/login` | 认证成功后恢复原操作意图 |

评论、分享、举报、素材库与发布确认可使用底部面板或子页面，支持关闭按钮、外部点击与 Escape；浏览器返回优先关闭当前面板。

## 核心体验

### 发现与游玩

- 打开首页即可发现作品，游客读取范围以服务端授权为准。
- Feed 中最多运行一个 Artifact。换页、离开页面或切到后台时暂停或卸载。
- 进入沉浸游玩后隐藏非游戏信息，保留清晰的退出入口及底部导航。
- 退出游玩恢复原 Feed 位置；触控游戏手势不能同时触发 Feed 翻页。
- 点赞、评论、账号收藏等写操作按权限要求登录；失败时回滚并允许重试。
- 网络错误、空 Feed、已下架、加载失败分别给出可理解状态。

### 原创、Remix 与素材

- 原创默认只要求一句话，可追加图片、视频、BGM 和资源库素材。
- Remix 明示原作、作者、权限和素材继承范围；血缘由服务端派生。
- 支持同一作品连续多轮修改，保留未提交输入和已选素材。
- 上传开关读取服务端能力。当前 API 未返回上限字段，按现有契约限制 8 项 / 4 MiB；上传提供进度与取消，失败后可重新选文件重试。
- 发布前说明素材可能随作品及允许的 Remix 进入交付产物。
- 页面刷新后恢复草稿和服务端任务；浏览器后台能力不足时不承诺持续上传。

### 生成、预览与发布

- 显示素材理解、方案生成、应用构建、自动验收等产品阶段，不暴露内部工具日志。
- 取消、重试和生成终态由服务端决定；客户端不把超时直接认定为失败。
- 私有预览必须真的能交互，再进入发布流程。
- 新候选版本仅作者可见，旧版继续公开；再次发布才替换公开版本。
- 发布带明确的 Artifact 版本，防止过期页面发布错误版本。
- 下架、撤销和过期挑战不得通过本地缓存继续播放。

### 个人中心与账号

- 查看个人资料、公开作品、草稿、失败任务、候选版本和版本时间线。
- 区分账号同步的收藏/最近游玩与浏览器本地记录。
- 登录后返回原路由并恢复创作或 Remix 草稿；点赞/收藏在登录后恢复意图；评论文本与评分跨登录保留，返回评论面板后由用户确认发送。
- 支持条款确认、资料完善、退出、隐私选择、屏蔽和举报记录。
- 数据导出、账号删除与重新认证依赖消费者 Web 登录方案，不能复用管理员身份。

### 公开传播

- `/a/:slug` 是完整 H5 的入口之一，不把创作与 Remix 强制交还 iOS。
- 保留作者与 Remix 归因；支持系统分享及复制链接回退。
- 社交预览需要边缘或服务端生成元信息，不能只依赖 SPA 执行 JavaScript。
- 计分作品可接入服务端的挑战与结果协议；分数按作品报告展示，不宣称防作弊排名。

## 适配与无障碍

覆盖 360–430px 移动视口及桌面布局，处理安全区、动态视口高度、软键盘、横竖屏、返回导航、弱网和后台恢复。关键按钮可触达，输入有标签，弹层管理焦点，减少动态效果偏好得到尊重。

## 范围边界

H5 不承担模型调用、Agent 编排、生成沙箱、验收终态、内容审核决策或后台运营。PWA 安装与离线体验可后续增强，首发不缓存私有素材、会话或可被撤销的交付内容来绕过服务端权限。
